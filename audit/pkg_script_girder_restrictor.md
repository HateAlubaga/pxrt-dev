## Findings

- `px_pipeline/testout/lua/script_girder_restrictor/girder_restrictor.lua:20` - high - GetCurrentWorm() returns nil for soft objects - If GetCurrentWorm() returns nil when called from a soft object's Message handler (which isn't pinned during construction), the null check passes but cw.CurWeapon dereference at line 23 will fail with "attempt to index a nil value" - Pin the current worm in E.CW cache before dispatching M_FRAME to soft objects
- `px_pipeline/testout/lua/script_girder_restrictor/girder_restrictor.lua:23` - med - CheckName called 5 times per frame per girder worm - The transpiled code chains 5 CheckName calls with `or` operators every M_FRAME when a worm holds a girder weapon, causing redundant weapon name normalization and cache lookups - Cache the CheckName result or rewrite the PX source to use a single weapon list check
- `px_pipeline/testout/lua/script_girder_restrictor/girder_restrictor.lua:26` - low - sqrt wraps __R__.add instead of direct addition - The transpiled expression `F.sqrt(__R__.add((dx * dx), (dy * dy)))` wraps two number multiplications with __R__.add (which checks for string concatenation), then passes the result to F.sqrt - The transpiler should detect numeric-only arithmetic and emit `F.sqrt((dx * dx) + (dy * dy))`
- `px_pipeline/testout/lua/script_girder_restrictor/girder_restrictor.lua:24-25` - low - landSelectX/landSelectY read current worm twice per frame - GS.landSelectX and GS.landSelectY both call E.curWorm() internally (lines pxrt_e_game.lua:188-193), so reading both fields queries the current worm address twice in the same frame - Cache E.curWorm() result in pxrt_e_game.lua gsFields closures when both landSelect fields are accessed in one frame

- `px_pipeline/testout/lua/utility_hangglider/paratest.lua:106-107,129-132` - high - TurnSide not exposed, glider direction logic broken - The transpiled code reads `self.Owner.TurnSide` (worm facing direction) to flip glider angle calculations, but TurnSide (offset 0x1A8) is only readable for engine-backed worm proxies, not from wormcallback `This` - The hand-written port stubs TurnSide as always 1 (main.lua:341), so left-facing worms will have inverted glider physics
